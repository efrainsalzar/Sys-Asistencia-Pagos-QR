# Infraestructura

Archivos para ejecutar los servicios y dependencias del sistema.

- `docker/`: imágenes y configuraciones específicas de contenedores.
- `compose/`: composiciones para desarrollo, pruebas y otros ambientes.
- `env/`: ejemplos de variables de entorno, nunca secretos reales.

La infraestructura no debe contener lógica de negocio de la aplicación.
