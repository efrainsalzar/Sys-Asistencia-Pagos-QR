# Consideraciones técnicas

- El registro de asistencia debe tardar menos de 5 segundos por persona.
- El envío del QR debe ejecutarse en segundo plano.
- El sistema debe seguir funcionando aunque WhatsApp tarde en responder.
- Debe existir una vista de monitoreo en tiempo real.
- Todos los movimientos deben quedar registrados para auditoría.

## Datos de auditoría

Cada operación debería guardar, como mínimo:

- Fecha y hora
- Método de pago
- Reunión
- Usuario que realizó la acción
