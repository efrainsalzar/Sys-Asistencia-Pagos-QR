# Sys-Asistencia-Pagos-QR

Sistema para registrar asistencia y gestionar pagos por QR o en efectivo durante una reunión.

## Qué hace

- Registra la asistencia de cada persona.
- Genera una orden de pago asociada a la reunión.
- Emite un QR único para el pago.
- Controla pagos pendientes, pagos por QR y pagos en efectivo.
- Mantiene historial y trazabilidad por reunión.
