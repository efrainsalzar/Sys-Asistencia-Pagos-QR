# Frontend Web

Aplicación web para usuarios, administración, asistencia, pagos, QR y reportes.

Estructura interna prevista:

- `app/`: rutas, layouts y páginas de Next.js.
- `components/`: componentes visuales reutilizables.
- `features/`: funcionalidades agrupadas por dominio.
- `lib/`: utilidades y configuración del frontend.
- `services/`: clientes HTTP, WebSocket e integraciones.
- `schemas/`: validaciones con Zod.
- `types/`: tipos propios del frontend.
- `public/`: recursos estáticos.
